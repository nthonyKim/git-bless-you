# git-bless-you

_당신에게 git의 축복이 있기를_


오늘 커피는 누가 사나 고민하다가 🤖 으로 만든 랜덤 뽑기


---

## ✨ 기능

| 기능      | 설명                                         |
| ------- | ------------------------------------------ |
| 인원 모드   | 인원 수 입력 후 각자 카드를 눌러 숫자 뽑기         |
| 이름 모드   | `hello, world` 같은 이름 목록을 쉼표 구분자로 넣고 각자 카드를 눌러 숫자 뽑기 |
| 결과 값    | 1 ~ 1000 사이 난수                    |

## 🕹 사용법

1. 입력 모드를 선택한다:
   * **인원** → 예: 6 → `라운드 시작`
   * **이름** → 예: `hello, world` → `라운드 시작`
2. 카드를 누르거나 자동 ROLL을 설정
3. 화면 상단 토스트 또는 하단 영역으로 최고, 최저 해당자 확인
