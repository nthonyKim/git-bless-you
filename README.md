# git-bless-you

_당신에게 git의 축복이 있기를_


오늘 커피는 누가 사나 고민하다가 🤖 으로 만든 랜덤 뽑기


---

## ✨ 기능

| 기능      | 설명                                         |
| ------- | ------------------------------------------ |
| 인원 모드   | 인원수 입력 후 각자 직접 `ROLL` 버튼을 눌러 숫자 뽑기         |
| 이름 모드   | `hello, world` 같은 이름 리스트 입력 → 자동 셔플 + 순차 공개 |
| 결과 값    | 1 ~ 1000 사이 난수                    |

## 🕹 사용법

1. 입력 모드를 선택한다:
   * **인원** → 예: 6 → `라운드 시작`
   * **이름** → 예: `hello, world` → `라운드 시작`
2. **ROLL** 버튼을 누르거나 이름 모드에서는 자동으로 순차 공개됨
3. 화면 상단 토스트 또는 하단 영역으로 최고, 최저 해당자 확인
